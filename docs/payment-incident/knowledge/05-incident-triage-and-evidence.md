# 支付故障分级与证据规范

文档 ID：`PI-KB-005`  
版本：`v1.0`  
生效日期：`2026-01-01`  
适用范围：支付故障诊断、升级和结果报告

## 1. 故障分级

【PI-KB-005-1】P1：疑似重复扣款、金额不一致、取消后支付成功、或超过 30 分钟仍无渠道最终状态。P1 必须人工介入，不允许 Agent 自动修复。

【PI-KB-005-2】P2：支付成功但订单未更新，且可以获得完整支付、回调和订单证据。可生成待审批回放草稿。P3：支付处理中未超过 15 分钟或渠道仍为 `PENDING`，仅监控和延迟复查。

## 2. 证据最小集

【PI-KB-005-3】诊断报告必须区分“事实”“推断”“建议”。事实需至少引用订单状态、支付记录或回调日志之一；建议回放时需同时具备订单、支付成功和回调失败三类证据。

【PI-KB-005-4】证据不足时，报告应列出缺少的字段和下一步查询，而不是声明根因。日志不存在不等价于回调未发送；可能是检索时间范围或日志保留期不足。

## 3. 报告模板

【PI-KB-005-5】每个诊断结论按以下格式输出：故障等级、观察到的事实、关联证据、推断、建议动作、是否需要人工审批、风险与待补证据。引用格式使用文档 ID 与段落编号，例如 `PI-KB-002-4`。
